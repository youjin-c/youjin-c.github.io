# Tweetquency

** _[Github Repo](https://github.com/youjinChung/tweequency)_**

  
  

Tweequency is Python automation for generative music.  
  
By hacking the TweetDeck interface, the performer can listen to the trending
hashtags in realtime, which shows different hashtags every time the performer
plays it.  
Each hashtag column plays its own drum sound and color.  
It is a performative visual and sound art for tweet orchestra.  
  

## System

Python, Javascript, [Selenium,](https://www.guru99.com/selenium-tutorial.html)
[TweetDeck](https://tweetdeck.twitter.com/)
